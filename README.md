## 🚀 Featured Projects

### ⏱️ OptiTime — Automated Timetable Generation System
> 📄 *Research paper accepted at **ICIA-MET 2026**, submitted for IEEE publication*

A constraint-based scheduling platform that generates **conflict-free university timetables** automatically.

- Constraint-driven algorithm generating timetables for **20+ courses in under 10 seconds**
- Handles theory and lab scheduling and shared-resource conflicts, with timetable validation
- Secure REST APIs and admin modules for departments, faculty and classrooms, tested with **4 academic years** of data
- Designed and built independently as first author and lead developer

`React.js` `Django` `Python` `PostgreSQL` `REST API`

A production booking platform built for a **large-scale sports championship**.

- Real-time room availability and booking management
- Secure end-to-end online payments via **Cashfree** payment gateway
- JWT authentication, session management and backend validation
- Deployed to production

`React.js` `Node.js` `Express.js` `MongoDB` `Tailwind CSS` `Cashfree`
